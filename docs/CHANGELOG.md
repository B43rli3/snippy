# Changelog

## 1.0.1

Window mode now captures the window you click, including the parts hidden behind another window. Version 1.0.0 cropped the frozen screen, so a window in front stayed visible inside the selected area.

The current disk image is [Snippy.dmg on the 1.0.1 release](https://github.com/B43rli3/snippy/releases/latest).

## 1.0.0 (archived)

First public release. The disk image remains on the [archived 1.0.0 release](https://github.com/B43rli3/snippy/releases/tag/v1.0.0) as `Snippy-1.0.0.dmg`. Use 1.0.1 instead.
